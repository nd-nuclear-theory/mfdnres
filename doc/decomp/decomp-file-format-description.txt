# It could be heplful to the user to add summary statistics, even though thse
#could in principle be derived from the table of eigenvalues.  In particular,
#the number of numerically *distinct* eigenvalues informs the largest useful
#number of Lanczos iterations.
#
#   num_entries (int): Number of entries in the table, which is equalt to the number
#   of irrep (or symmetry subspace) tuple labels. 
#
#   num_eigenvalues (int): Number of numerically distinct eigenvalues (at numerical
#   precision, but this should be pretty accurate, if the eigenalue formulas are
#   applied identically across entries.  Or, with a little more coding work, a numerical
#   tolerance could be introduced when deducing this count.
